# Veterinaria Malfi 🐾

Sistema de gestión integral para veterinaria desarrollado con tecnología full-stack moderna.

## Descripción

Proyecto fullstack que permite gestionar:
- **Pacientes** (mascotas y datos de propietarios)
- **Citas y atenciones** veterinarias
- **Historiales** médicos
- **Reportes** y estadísticas
- **Gestión de usuarios** con autenticación

## 🛠️ Tecnologías

### Frontend
- **React 19** - Framework UI
- **Vite** - Build tool
- **TailwindCSS** - Estilos
- **Bootstrap 5** - Componentes UI
- **Axios** - Cliente HTTP
- **React Router** - Navegación
- **React Hook Form** - Manejo de formularios
- **Recharts** - Gráficos y análisis
- **Lucide React** - Iconos

### Backend
- **Node.js + Express.js** - Servidor REST API
- **MySQL** - Base de datos
- **JWT** - Autenticación
- **Bcrypt** - Encriptación de contraseñas
- **Nodemailer** - Envío de emails
- **jsPDF** - Generación de reportes en PDF
- **XLSX** - Exportación de datos a Excel
